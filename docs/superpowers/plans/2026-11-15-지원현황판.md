# 지원 현황판 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공고에서 지원서를 '담고', 지원서마다 전형 단계를 기록하면, 카드가 그 단계에 맞는 "지금 할 일"(문항 해설 → 진단 → 면접 연습)을 하나씩 보여준다.

**Architecture:**
- 기존 `projects` 테이블에 `stage`·`stage_steps`·`rejected` 칸을 더하고, 기존 지원서 API(`api/projects.js`, `api/projects/[projectId]/index.js`)를 넓힌다. 새 서버 함수는 없다.
- 단계 계산은 `client/src/lib/applicationStages.ts`, 단계별 행동은 `client/src/lib/nextAction.ts`가 맡는다. 둘 다 순수 함수다.
- 화면은 공고의 담기 버튼(`JobSaveButton`), `/my` 목록(`ApplicationList`·`StageMenu`), 면접 시작 화면의 `?application=` 미리 고르기만 바꾼다.

**Tech Stack:** React 19 + Wouter + Tailwind4 · Vercel Serverless ESM JS · Prisma 7 + Supabase Postgres · Vitest · pnpm

**Spec:** `docs/superpowers/specs/2026-11-15-공고-담기-지원현황-design.md`

## Global Constraints

- `pnpm`만 쓴다. 의존성을 추가하지 않는다.
- 기본 단계 키는 이 순서로 고정한다: `interest`, `writing`, `submitted`, `doc_passed`, `interview`, `offer`.
- 직접 넣은 단계 키는 `^c_[a-z0-9]{8}$`, 이름은 다듬은 뒤 1~20자, 단계는 모두 합쳐 6~12개, 마지막은 항상 `offer`다.
- DB 기본값은 `stage = 'writing'`, `stage_steps = NULL`, `rejected = false`이고, 담기만 `interest`로 만든다.
- API는 `stageSteps: null`을 받지 않는다. 기본 목록으로 되돌릴 때도 클라이언트가 기본 6단계 배열을 보낸다.
- 응답 필드 이름은 `stage`, `stage_steps`, `rejected`, `posting_slug`다. 기존 필드 이름은 바꾸지 않는다.
- Vercel 함수 수 12개와 `vite.config.ts`의 `apiRoute()` 매핑은 바뀌지 않아야 한다.
- 화면 문구는 `client/src/copy/`에 둔다. 새 문구는 사용자 검수 대상이다.
- 강조는 기존 톤(흰 버튼·`bg-brand`)으로 하고, 그라데이션·파란 틴트 카드·떠 있는 알약 배지는 쓰지 않는다.
- 기존 파일에 `pnpm format`이나 prettier를 돌리지 않는다. 손으로 주변 스타일에 맞춘다.
- 운영 DB 마이그레이션 적용과 푸시는 사용자 승인을 받은 뒤에 한다(Task 9).
- 클릭 기록: 담기는 `content_cta_click`의 `job-save:<slug>`, 지금 할 일은 `next-action:<기준 단계>:<행동>`이다.

`lib/application-drafts.js`의 `MAX_DRAFT_EXPERIENCES` 선언 아래에 추가한다:

```js
// 지원 현황판 단계(11-15). 기본 6단계는 지우거나 순서를 못 바꾸고, 직접 넣은 단계만 끼워 넣는다.
export const DEFAULT_STAGE_KEYS = ["interest", "writing", "submitted", "doc_passed", "interview", "offer"];
const CUSTOM_STAGE_KEY = /^c_[a-z0-9]{8}$/;
const MAX_STAGE_STEPS = 12;
const MAX_STAGE_LABEL = 20;
const MAX_STAGE_KEY = 40;
```

파일 맨 끝에 추가한다:

```js
// 단계 목록 검사. null 은 받지 않는다(JSON 칸 null 은 Prisma.DbNull 이 필요해서, 되돌리기도 기본 배열로 보낸다).
export function normalizeStageSteps(value) {
  if (!Array.isArray(value) || value.length < DEFAULT_STAGE_KEYS.length || value.length > MAX_STAGE_STEPS) throw invalid();
  const seen = new Set();
  const builtins = [];
  const steps = value.map((item) => {
    if (!isRecord(item) || typeof item.key !== "string" || seen.has(item.key)) throw invalid();
    seen.add(item.key);
    if (DEFAULT_STAGE_KEYS.includes(item.key)) {
      onlyKeys(item, ["key"]);
      builtins.push(item.key);
      return { key: item.key };
    }
    if (!CUSTOM_STAGE_KEY.test(item.key)) throw invalid();
    onlyKeys(item, ["key", "label"]);
    return { key: item.key, label: requiredText(item.label, MAX_STAGE_LABEL) };
  });
  if (builtins.join(",") !== DEFAULT_STAGE_KEYS.join(",") || steps[steps.length - 1].key !== "offer") throw invalid();
  return steps;
}

/** 저장된 단계 목록(NULL 이면 기본)의 키들. */
export function stageKeysOf(steps) {
  return Array.isArray(steps) ? steps.map((step) => step.key) : [...DEFAULT_STAGE_KEYS];
}
```

export function normalizeProjectCreate(body) {
  if (!isRecord(body)) throw invalid();
  onlyKeys(body, ["company", "jobKeyword", "deadline", "postingSlug", "questions", "stage"]);
  let postingSlug = null;
  if (body.postingSlug !== undefined && body.postingSlug !== null) {
    if (typeof body.postingSlug !== "string" || !SLUG_PATTERN.test(body.postingSlug)) throw invalid();
    postingSlug = body.postingSlug;
  }
  // 새로 만들 때 고를 수 있는 단계는 '관심'(공고 담기)뿐이다. 없으면 DB 기본값(writing).
  if (body.stage !== undefined && body.stage !== "interest") throw invalid();
  return {
    company: requiredText(body.company, 100),
    jobKeyword: optionalText(body.jobKeyword, 100),
    deadline: optionalDate(body.deadline),
    postingSlug,
    stage: body.stage,
    // 새 지원서에는 초안 경험이 있을 수 없다. 소유 확인 없이 저장되지 않게 버린다.

  };
}

```ts
import { APPLICATION_BOARD_COPY } from "@/copy/applicationBoardCopy";

/**
 * 지원 현황판 단계 계산(11-15). 서버 규칙(lib/application-drafts.js normalizeStageSteps)과 같다:
 * 기본 6단계는 고정·순서 유지, 직접 단계(c_ + 8자)만 끼워 넣고 지운다, 최대 12개, 마지막은 offer.
 * 설계: docs/superpowers/specs/2026-11-15-공고-담기-지원현황-design.md
 */
export const DEFAULT_STAGE_KEYS = ["interest", "writing", "submitted", "doc_passed", "interview", "offer"] as const;
export type DefaultStageKey = (typeof DEFAULT_STAGE_KEYS)[number];
export type StageStep = { key: string; label?: string };
export type StageFields = { stage?: string; stage_steps?: StageStep[] | null; rejected?: boolean };

const MAX_STEPS = 12;
const MAX_LABEL = 20;

export function isDefaultStage(key: string): key is DefaultStageKey {
  return (DEFAULT_STAGE_KEYS as readonly string[]).includes(key);
}

export function resolveSteps(steps?: StageStep[] | null): StageStep[] {
  return Array.isArray(steps) && steps.length > 0 ? steps : DEFAULT_STAGE_KEYS.map((key) => ({ key }));
}

export function stageLabel(step: StageStep): string {
  return isDefaultStage(step.key) ? APPLICATION_BOARD_COPY.stages[step.key] : step.label ?? step.key;
}

export function currentStep(p: StageFields): StageStep {
  const steps = resolveSteps(p.stage_steps);
  return steps.find((step) => step.key === (p.stage ?? "writing")) ?? { key: "writing" };
}

/** 직접 단계는 바로 앞의 기본 단계와 같은 할 일을 보여 준다. */
export function baseStage(steps: StageStep[], key: string): DefaultStageKey {
  if (isDefaultStage(key)) return key;
  const index = steps.findIndex((step) => step.key === key);
  for (let i = index - 1; i >= 0; i -= 1) {
    const candidate = steps[i].key;
    if (isDefaultStage(candidate)) return candidate;
  }
  return "writing";
}

export function canInsertAfter(steps: StageStep[], afterKey: string): boolean {
  return afterKey !== "offer" && steps.length < MAX_STEPS && steps.some((step) => step.key === afterKey);
}

function randomStageKey(): string {
  const alphabet = "abcdefghijklmnopqrstuvwxyz0123456789";
  const bytes = crypto.getRandomValues(new Uint8Array(8));
  return `c_${Array.from(bytes, (b) => alphabet[b % alphabet.length]).join("")}`;
}

export function insertStepAfter(
  steps: StageStep[],
  afterKey: string,
  label: string,
  makeKey: () => string = randomStageKey,
): StageStep[] {
  const trimmed = label.trim();
  if (!canInsertAfter(steps, afterKey) || trimmed.length === 0 || trimmed.length > MAX_LABEL) {
    throw new Error("cannot insert stage");
  }
  const index = steps.findIndex((step) => step.key === afterKey);
  return [...steps.slice(0, index + 1), { key: makeKey(), label: trimmed }, ...steps.slice(index + 1)];
}

export function removeStep(steps: StageStep[], key: string): StageStep[] {
  if (isDefaultStage(key)) throw new Error("cannot remove default stage");
  return steps.filter((step) => step.key !== key);
}

export function isFinished(p: StageFields): boolean {
  return Boolean(p.rejected) || p.stage === "offer";
}

/** 진행 중 / 결과 나옴으로 나눈다. 순서는 부모가 정한 것(sortApplications)을 그대로 둔다. */
export function splitBoard<T extends StageFields>(items: T[]): { active: T[]; finished: T[] } {
  return { active: items.filter((p) => !isFinished(p)), finished: items.filter(isFinished) };
}
```

import { APPLICATION_BOARD_COPY } from "@/copy/applicationBoardCopy";
import { baseStage, currentStep, resolveSteps, type StageFields } from "@/lib/applicationStages";
import { GUIDE_SUMMARIES, guidePath } from "@/lib/guideSummaries";

/**
 * 지원서 한 장의 "지금 할 일"(설계 3.4절 표). 단계는 이 행동을 고르는 신호다.
 * 가이드는 본문 없는 GUIDE_SUMMARIES 를 쓴다(lib/guides.ts 는 본문을 통째로 실어 /my 번들이 무거워진다).
 */
export type NextActionKind = "guide-questions" | "write" | "continue" | "diagnose" | "report" | "prepare" | "interview" | "paste";
export type NextAction = {
  kind: NextActionKind;
  label: string;
  reason: string;
  href: string;
  track: string;
  secondary?: { label: string; href: string };
};
export type GuideRef = { slug: string; company: string | null; category: string };
export type NextActionInput = StageFields & {
  id: string;
  company_name: string | null;
  answered_count?: number;
  latest_analysis_id?: string | null;
  latest_status?: string | null;
};

const INTERVIEW_CATEGORY = "면접 후기";
const companyKey = (name: string | null | undefined) => (name ?? "").replace(/\s+/g, "").toLowerCase();

/** 회사 이름이 정확히 같은 글만. 애매하면 링크를 숨긴다(틀린 연결보다 안 뜨는 쪽). */
function findGuide(company: string | null, guides: readonly GuideRef[], interview: boolean): GuideRef | undefined {
  const key = companyKey(company);
  if (!key) return undefined;
  return guides.find((g) => companyKey(g.company) === key && (g.category === INTERVIEW_CATEGORY) === interview);
}

export function nextAction(p: NextActionInput, guides: readonly GuideRef[] = GUIDE_SUMMARIES): NextAction | null {
  if (p.rejected || p.stage === "offer") return null;
  const steps = resolveSteps(p.stage_steps);
  const stage = baseStage(steps, currentStep(p).key);
  const copy = APPLICATION_BOARD_COPY.next;
  const workspace = `/my/${encodeURIComponent(p.id)}`;
  const interviewHref = `/my/interview-practice?application=${encodeURIComponent(p.id)}`;
  const hasText = (p.answered_count ?? 0) > 0 || Boolean(p.latest_analysis_id);
  const make = (kind: NextActionKind, text: { label: string; reason: string }, href: string): NextAction => ({
    kind, label: text.label, reason: text.reason, href, track: `next-action:${stage}:${kind}`,
  });

  if (stage === "interest") {
    const guide = findGuide(p.company_name, guides, false);
    return guide ? make("guide-questions", copy.guideQuestions, guidePath(guide)) : make("write", copy.write, workspace);
  }
  if (stage === "writing") {
    if (p.latest_analysis_id && p.latest_status === "SUCCESS") {
      return make("report", copy.report, `/report-new?analysisId=${encodeURIComponent(p.latest_analysis_id)}`);
    }
    return (p.answered_count ?? 0) > 0 ? make("diagnose", copy.diagnose, workspace) : make("continue", copy.continue, workspace);
  }
  if (stage === "submitted") {
    return hasText ? make("prepare", copy.prepare, interviewHref) : make("paste", copy.paste, workspace);
  }
  // doc_passed · interview
  const action = hasText ? make("interview", copy.interview, interviewHref) : make("paste", copy.paste, workspace);
  const guide = findGuide(p.company_name, guides, true);
  return guide ? { ...action, secondary: { label: copy.interviewGuide, href: guidePath(guide) } } : action;
}

```tsx
import { useEffect, useState } from "react";
import { Link } from "wouter";
import AnalyzeLoginModal from "@/components/analyze/AnalyzeLoginModal";
import { APPLICATION_BOARD_COPY } from "@/copy/applicationBoardCopy";
import type { JobPostingListing } from "@/constants/jobPostings";
import { useAuth } from "@/contexts/AuthContext";
import { useSubmitAfterLogin } from "@/hooks/useSubmitAfterLogin";
import { sendFunnelEvent } from "@/lib/siteVisits";
import { listApplications, saveJobPosting } from "@/lib/workspace";

const COPY = APPLICATION_BOARD_COPY.save;
const RETURN_FLAG = "save";

/**
 * 공고 담기(11-15). 로그인하지 않았으면 로그인 창을 띄우고, 로그인이 끝나면 자동으로 담는다.
 * 카카오는 페이지를 떠났다 돌아오므로 redirectPath 에 ?save=1 을 붙여 돌아온 뒤 한 번 담고 지운다.
 * 프리렌더(SSR)와 첫 클라이언트 렌더는 isLoading 이라 둘 다 "☆ 담기"로 같다.
 */
export default function JobSaveButton({ listing }: { listing: JobPostingListing }) {
  const { isAuthenticated, isLoading } = useAuth();
  const [state, setState] = useState<"idle" | "saving" | "saved" | "failed">("idle");
  const [loginOpen, setLoginOpen] = useState(false);
  const [returnedFromLogin] = useState(
    () => typeof window !== "undefined" && new URLSearchParams(window.location.search).get(RETURN_FLAG) === "1",
  );

  const save = async () => {
    setState("saving");
    try {
      await saveJobPosting({ postingSlug: listing.slug, company: listing.company, deadline: listing.closesAt });
      setState("saved");
    } catch {
      setState("failed");
    }
  };

  const afterLogin = useSubmitAfterLogin({
    isAuthenticated,
    onSubmit: () => {
      if (returnedFromLogin) window.history.replaceState(null, "", window.location.pathname);
      void save();
    },
    initiallyArmed: returnedFromLogin,
  });

  useEffect(() => {
    if (isAuthenticated) setLoginOpen(false);
  }, [isAuthenticated]);

  // 이미 담은 공고인지. 편의 표시라 실패하면 그냥 "담기"로 둔다(다시 담아도 서버가 하나만 둔다).
  useEffect(() => {
    if (isLoading || !isAuthenticated) return;
    let alive = true;
    listApplications()
      .then((rows) => { if (alive && rows.some((row) => row.posting_slug === listing.slug)) setState("saved"); })
      .catch(() => {});
    return () => { alive = false; };
  }, [isLoading, isAuthenticated, listing.slug]);

  const onClick = () => {
    void sendFunnelEvent("content_cta_click", `job-save:${listing.slug}`);
    if (!isAuthenticated) {
      afterLogin.arm();
      setLoginOpen(true);
      return;
    }
    void save();
  };

  return (
    <div className="mt-5">
      {state === "saved" ? (
        <Link
          href="/my"
          className="inline-flex h-11 items-center rounded-[12px] bg-ink px-4 text-[14px] font-semibold text-white transition-colors hover:bg-ink-2"
        >
          {COPY.saved}
        </Link>
      ) : (
        <button
          type="button"
          onClick={onClick}
          disabled={state === "saving"}
          className="inline-flex h-11 items-center rounded-[12px] bg-ink px-4 text-[14px] font-semibold text-white transition-colors hover:bg-ink-2 disabled:opacity-60"
        >
          {state === "saving" ? COPY.saving : COPY.idle}
        </button>
      )}
      <p className={`mt-2 text-[13px] ${state === "failed" ? "text-danger" : "text-ink-4"}`}>
        {state === "failed" ? COPY.failed : COPY.hint}
      </p>
      <AnalyzeLoginModal
        open={loginOpen}
        onClose={() => { afterLogin.disarm(); setLoginOpen(false); }}
        redirectPath={`/jobs/${listing.slug}?${RETURN_FLAG}=1`}
        description={COPY.loginDescription}
      />
    </div>
  );
}
```

import {
  canInsertAfter, currentStep, insertStepAfter, isDefaultStage, removeStep, resolveSteps, stageLabel,

} from "@/lib/applicationStages";

export type StagePatch = { stage?: string; stageSteps?: StageStep[]; rejected?: boolean };
const COPY = APPLICATION_BOARD_COPY.menu;

/**
 * 단계 배지 + 펼침 메뉴. 고르면 바로 저장한다(한 번 누르기). 저장 실패 처리는 onChange 를 넘긴 쪽이 한다.
 * 카드 전체가 지원서 화면 링크라, 이 안의 클릭은 바깥으로 올리지 않는다.
 */
export default function StageMenu({ project, onChange }: { project: StageFields & { id: string }; onChange: (patch: StagePatch) => Promise<void> }) {
  const [open, setOpen] = useState(false);
  const [adding, setAdding] = useState(false);
  const [label, setLabel] = useState("");
  const rootRef = useRef<HTMLDivElement>(null);
  const steps = resolveSteps(project.stage_steps);
  const current = currentStep(project);
  const currentName = stageLabel(current);
  const badge = project.rejected ? APPLICATION_BOARD_COPY.rejectedSuffix(currentName) : currentName;

  useEffect(() => {
    if (!open) return;
    const close = (event: MouseEvent) => { if (!rootRef.current?.contains(event.target as Node)) setOpen(false); };
    document.addEventListener("mousedown", close);
    return () => document.removeEventListener("mousedown", close);
  }, [open]);

  const run = (patch: StagePatch) => { setOpen(false); setAdding(false); setLabel(""); void onChange(patch); };

  return (
    <div ref={rootRef} className="relative z-10 inline-block" onClick={(e) => e.stopPropagation()}>
      <button
        type="button"
        aria-haspopup="menu"
        aria-expanded={open}
        onClick={() => setOpen((v) => !v)}
        className={`inline-flex h-7 items-center whitespace-nowrap rounded-[8px] px-2.5 text-[12.5px] font-bold ${project.rejected ? "bg-fill text-ink-4" : "bg-fill text-ink-2"} hover:bg-fill-soft`}
      >
        {badge} ▾
      </button>
      {open && (
        <div role="menu" aria-label={COPY.title} className="absolute left-0 top-9 w-56 rounded-[14px] border border-line bg-surface p-1.5 shadow-[0_8px_24px_rgba(0,0,0,0.12)]">
          {steps.map((step) => (
            <div key={step.key} className="flex items-center">
              <button
                type="button"
                role="menuitemradio"
                aria-checked={step.key === current.key}
                onClick={() => run({ stage: step.key })}
                className={`flex-1 rounded-[9px] px-2.5 py-2 text-left text-[14px] ${step.key === current.key ? "font-bold text-ink" : "text-ink-2"} hover:bg-fill-soft`}
              >
                {stageLabel(step)}
              </button>
              {!isDefaultStage(step.key) && step.key !== current.key && (
                <button
                  type="button"
                  aria-label={COPY.removeStep(stageLabel(step))}
                  onClick={() => run({ stageSteps: removeStep(steps, step.key) })}
                  className="rounded-[8px] px-2 py-1 text-[13px] text-ink-4 hover:bg-fill-soft"
                >
                  ✕
                </button>
              )}
            </div>
          ))}
          <div className="mt-1 border-t border-line-soft pt-1">
            {adding ? (
              <form
                className="flex gap-1.5 p-1"
                onSubmit={(e) => {
                  e.preventDefault();
                  if (!label.trim()) return;
                  run({ stageSteps: insertStepAfter(steps, current.key, label) });
                }}
              >
                <input
                  autoFocus
                  maxLength={20}
                  value={label}
                  onChange={(e) => setLabel(e.target.value)}
                  placeholder={COPY.addPlaceholder}
                  aria-label={COPY.addAfter(currentName)}
                  className="h-8 min-w-0 flex-1 rounded-[8px] border border-line px-2 text-[13.5px]"
                />
                <button type="submit" className="h-8 rounded-[8px] bg-brand px-2.5 text-[13px] font-semibold text-white">{COPY.addConfirm}</button>
              </form>
            ) : (
              canInsertAfter(steps, current.key) && (
                <button type="button" onClick={() => setAdding(true)} className="w-full rounded-[9px] px-2.5 py-2 text-left text-[13.5px] text-ink-3 hover:bg-fill-soft">
                  {COPY.addStep}
                </button>
              )
            )}
            <button
              type="button"
              onClick={() => run({ rejected: !project.rejected })}
              className="w-full rounded-[9px] px-2.5 py-2 text-left text-[13.5px] text-ink-3 hover:bg-fill-soft"
            >
              {project.rejected ? COPY.unmarkRejected : COPY.markRejected}
            </button>
          </div>
        </div>
      )}
    </div>
  );
}
