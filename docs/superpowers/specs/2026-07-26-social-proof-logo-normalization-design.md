# Social Proof 로고 정렬·가독성 보정 설계

## 목표

Social Proof 마키의 18개 기업 로고를 동일한 시각 기준선에 맞추고, 기본 상태에서도 브랜드를 식별할 수 있게 한다. 기존의 미니멀한 분위기와 hover 시 원색 복원은 유지한다.

## 확인된 원인

- 현재 이미지가 로고 레일의 높이보다 큰 원본 비율로 렌더링되는 경우가 있어, 세로형 로고가 하단에서 잘린다.
- 회사마다 원본 비율과 내부 여백이 달라 단일 크기 상자만으로는 체감 크기를 맞출 수 없다.
- 기본 필터가 `grayscale(1) opacity(0.55)`여서 어두운 배경에서 일부 로고의 식별성이 낮다.

## 설계

### 1. 공통 정렬 프레임

- `.social-proof-logo-shell`은 고정 높이의 상대 위치 프레임이 된다.
- 로고 이미지는 절대 위치와 `max-width / max-height`로 프레임 안에 수용한다. 이미지 자체가 레일 높이를 늘리거나 아래로 넘치지 않는다.
- 모든 로고의 세로 중심은 프레임 중앙에 맞춘다.

### 2. 기업별 시각 배율

- `SuccessfulCompany`에 `logoScale` 숫자 속성을 추가한다.
- 기본 로고 높이는 공통으로 두고, 정사각형·세로형·내부 여백이 큰 로고에만 보수적으로 배율을 적용한다.
- 배율은 레이아웃 크기를 바꾸지 않는 `transform: scale()`으로 적용한다. 각 값은 데이터 배열에서만 수정한다.
- 긴 워드마크는 가로 최대 폭을 넘지 않으며, 세로형 로고는 같은 기준선에서 너무 작아 보이지 않도록 보정한다.

### 3. 기본 색상과 상호작용

- 기본 상태는 완전 흑백 대신 부분 그레이스케일과 더 높은 불투명도를 쓴다.
- hover에서는 필터를 제거해 원래 색으로 복원한다.
- 과한 그림자나 배경 패널은 추가하지 않는다.

## 변경 범위

- `client/src/constants/socialProof.ts`: 회사별 `logoScale` 데이터
- `client/src/components/SocialProofSection.tsx`: 배율을 CSS custom property로 전달
- `client/src/index.css`: 고정 정렬 프레임, 크기 제한, 가독성 필터
- `client/src/components/SocialProofSection.test.tsx`: 로고 보정 데이터와 렌더링 속성 검증

## 완료 기준

- 데스크톱과 모바일에서 모든 로고의 렌더링 높이가 레일 높이를 넘지 않는다.
- 18개 로고는 모두 수직 중앙에 정렬된다.
- 기본 상태에서 로고 이름·형태를 식별할 수 있고, hover 시 원색으로 바뀐다.
- 마키의 좌→우 연속 루프와 reduced-motion 동작은 유지된다.
