# 인사이트 리포트 생성 120초 제한 설계

## 목표

인사이트 리포트 생성 요청이 서버리스 실행 제한 때문에 60초에 종료되지 않도록, 서버 실행 최대 시간을 120초로 맞춘다.

## 현재 상태

- 클라이언트 `client/src/pages/Analyze.tsx`는 이미 요청을 120초 후 취소한다.
- 서버 `api/analyze.js`의 `maxDuration`은 60초라 배포 환경에서 클라이언트 제한보다 먼저 요청이 종료될 수 있다.
- AI 모델 한 번의 호출은 25초로 제한되며, 재시도 가능한 오류에서는 폴백 모델을 호출한다.

## 결정

`api/analyze.js`의 `maxDuration`을 `120`으로 변경한다. 모델별 25초 제한, 3초 폴백 대기, 클라이언트의 120초 취소 제한은 변경하지 않는다.

이 경계는 모델 한 번의 무응답으로 전체 요청을 장시간 묶지 않으면서, 폴백 모델 호출이 필요한 경우에 요청이 60초에서 조기 종료되는 문제를 없앤다.

## 오류 처리

120초 안에 성공하지 못하면 클라이언트의 `AbortController`가 요청을 중단하고 기존 시간 초과 오류 경로를 사용한다. 서버에서 모델별 호출이 시간 초과되면 기존 폴백/오류 처리 흐름을 유지한다.

## 검증

`api/analyze.js`가 120초의 서버리스 최대 실행 시간을 내보내는지 회귀 테스트로 고정한다. 이어서 해당 테스트와 TypeScript 검사 및 프로덕션 빌드를 실행한다.
