## 무엇을 만들었나

리포트를 읽은 AI 면접관과 카메라·마이크를 켜고 실시간으로 면접을 보고, 끝나면 답변·시선·자세 피드백을 받는다.

```
리포트(예상 질문 아래 카드) → /my/interview-practice/start → 장비 점검·동의 → 세션 생성(이용권 예약)
→ 입장권 발급 → 브라우저 ↔ Gemini Live(gemini-3.8-live) 직결 → 받아쓰기를 대화 글로 저장
→ 종료 → 사진 12장 + 대화 글로 피드백(gemini-3.8-flash) → /my/interview-practice/:id 에서 다시 보기
```

## 정한 규칙

- **이용권:** 입장권을 받는 순간부터 사용으로 본다(서버는 대화를 볼 수 없다). 2분 안에 끝나고 답변 2회 미만이면 돌려준다(계정당 30일 2회). 피드백이 성공하면 확정, 3회 실패하면 돌려준다. 입장권 없이 10분이 지나면 취소·환불. 끝난 뒤 24시간 피드백을 안 받으면 확정.
- **동시 1건, 15분에 3건 생성, 세션당 입장권 5회(첫 발급 + 재연결 4회), 마감 = 시작 + 15분(짧은 연습 5분) + 1분.**
- **잠그는 것:** 모델, 면접관 지시, 자소서·질문·공고, 받아쓰기·압축·이어받기 설정을 입장권에 넣는다. 브라우저에는 모델 이름과 이어받기 값만 간다. 리포트의 모범 답변은 넘기지 않는다.
- **저장:** 대화 글(자동 받아쓰기)과 피드백만. 음성·영상·사진은 저장하지 않는다. 사진은 브라우저 메모리에만 있다가 피드백 요청 때 한 번 보내고 버려진다.
- **피드백 범위:** 답변 구조·근거, 시선·자세·화면 구도처럼 보이는 행동만(사진 3장 이상에서 보인 것). 표정·감정·성격·외모·점수·합격 가능성은 프롬프트에서 빼고 서버 후처리로도 걸러 낸다. 받아쓰기 한계 때문에 맞춤법·군말·말 속도는 평가하지 않는다.
- **이름:** "AI 면접 연습". 사람과 하는 멘토링 모의면접(`/mentoring`)과 다르다.
- **스위치 기본 꺼짐:** `interview_enabled=false` 라 코드가 합쳐져 배포돼도 사용자에게 보이지 않는다.

실측으로 고친 것: 임시 토큰 REST 본문은 문서 예시 `liveConnectConstraints` 가 아니라 `bidiGenerateContentSetup`(setup 내용을 바로 펼침) + `fieldMask`. `fieldMask` 에 적은 필드만 토큰이 덮어쓰고, `sessionResumption` 은 빼서 브라우저가 이어받기 handle 을 보낸다(`live-token.js`, `liveProtocol.ts`, 시험 도구). 시험 도구에 사진 간격·침묵 판정 옵션과 간격별 비용 차단 단가를 더했다.

**아직 못 한 것**
- 로그인한 상태의 전체 흐름(카드 → 설정 → 면접 → 피드백)을 사람이 직접 돌리지 않았다. 실제 마이크 경로(AudioWorklet)도 미확인.
- 침묵 판정(1.2초) 값 결정. 3초 쉬면 끼어들므로 직접 말해 보고 정한다.
- 비용 줄이기 네 가지(사진 10초 간격, 면접관 말할 때 사진·마이크 전송 멈춤, 압축 4만→2만 토큰)는 적용했지만 실측은 아직. 실제 한 번 더 돌려 토큰 합산을 본다.
- 압축(`contextWindowCompression`, 앞부분 버리기)이 발동했을 때 면접관이 앞 답변을 얼마나 잊는지 미확인(15분 실측은 5만 토큰에서 끝나 발동 안 함).

## 로컬에서 돌리는 법

1. (처음 한 번) 로컬 DB: `createdb preview_interview_dev` 뒤 `DATABASE_URL=postgresql://<내 계정>@localhost:5432/preview_interview_dev DIRECT_URL=<같은 값> pnpm exec prisma db push`
2. 개발 서버: Code 탭의 `interview-dev`(워크트리에서 뜨고, DB 만 로컬로 덮어쓴다. 로그인은 운영 Supabase 그대로)
3. 로그인한 뒤 403 이 나면 시드: `DATABASE_URL=... node scripts/manual/seed-local-interview.mjs --user-id <Supabase uid> --email <로그인 이메일>` → 출력된 `report` 주소로 이동
4. 키: 입장권·피드백은 `INTERVIEW_GEMINI_API_KEY`(없으면 `GEMINI_API_KEY`)를 쓴다. 측정 전용 키를 `.env` 에 `INTERVIEW_GEMINI_API_KEY=` 로 두면 면접 비용이 분석 비용과 섞이지 않는다.
5. 1단계 시험: `scripts/manual/live-probe/README.md`
